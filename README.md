# YanMod

Моды, готовые сборки и переводы для Yandere Simulator. Архивы лежат в [Releases](https://github.com/bylka882-png/YanMod/releases), манифесты и изображения — в этом репозитории.

## Веб-каталог

`index.html` — один файл без зависимостей и сборки. Это та же страница, что открыта на GitHub Pages.

Что она делает:

- показывает все моды из репозитория;
- ищет по названию, автору и описанию;
- фильтрует по разделам `PM`, `Build`, `TR`, `ML`, `Mod`, `Plugin`, `Translate`;
- проверяет совместимость с выбранной версией игры (`U4`, `U5`, `U6`, `U17`, `U19`, `U20`) по полю `game_versions`;
- в окне мода показывает версии, скриншоты и GIF, описание, README и changelog, зависимости, `affected_files`, ссылки автора и видео YouTube;
- скачивает архив, включая многотомный: браузер получает все части.

Страница только скачивает файлы в папку загрузок. Она ничего не устанавливает и не распаковывает.

Открыть локально: сохранить `index.html` и дважды щёлкнуть. Нужен интернет — данные читаются из GitHub: список файлов через Tree API (при лимите запросов — через jsDelivr), манифесты с `raw.githubusercontent.com`. Кэш — 6 часов, кнопка «Обновить» загружает заново.

Без сети показывается последняя сохранённая копия, если она была. В приватном режиме браузер может запретить кэш. Для многотомного архива браузер может спросить разрешение на несколько загрузок.

Сама страница обновляется вместе с `index.html`: GitHub Pages отдаёт этот файл из репозитория.

## Структура

```
YanMod/
├─ build/       готовые сборки
├─ mod/         обычные моды
├─ PM/          Pose Mod
├─ TR/          текстуры
├─ ML/          загрузчики: BepInEx, PoseMod
├─ Plugins/     плагины BepInEx
├─ Translate/   переводы
├─ index.toml   список файлов каталога
├─ index.html   веб-каталог
└─ README.md
```

Один мод — одна папка с `info.toml` в подпапке версии. Верхняя папка подсказывает раздел, но настоящий тип — поле `type` в файле. `README.md` и `changelog.md` лежат в папке мода, общие для всех версий. Изображения — в папке версии.

```
build/ChristmasPartyMod/
├─ 1.0.0/
│  └─ info.toml
├─ 1.webp
├─ 2.webp
├─ ico.webp
├─ README.md
└─ changelog.md
```

Одинаковый `id` в разных папках = версии одного мода. Они собираются в одну карточку и сортируются по `mod_version`.

`index.toml` — список файлов для лаунчера и веб-страницы. Пишется автоматикой, руками не редактируется.

## Манифест `info.toml`

Полные правила — в [toml.md](toml.md). Готовый пример — в [пример.toml](пример.toml).

```toml
[info]
id = "CPM"
name = "Christmas Party Mod"
author = "Rommy"
type = "Build"
game_versions = "U4-U6"
mod_version = "1.0.0"
tags = ["christmas", "party"]

[credits]
youtube = "https://www.youtube.com/@Rommy_ys"

[description]
en = "A mod that adds a Christmas party and holiday social challenges"
ru = "Мод, добавляющий рождественскую вечеринку и праздничные социальные челленджи"
videos = [
    "https://www.youtube.com/watch?v=wtUnoRElt44",
]

[download.part1]
url = "https://github.com/bylka882-png/YanMod/releases/download/ChristmasParty/ChristmasParty.7z.001"
size = 1939865600
sha256 = "3E3FDF871364CF3367182A9D1B7B3C4C498111C1C1FE32DC02007BEB44859F52"

[files]
config = "BepInEx\\config\\BepInEx.cfg"
affected_files = [
    "PoseMod\\Modules\\pmcore00.dll",
]
installed = [
    { id = "posemod", v = "5" },
    { id = "bee" },
]
dependencies = [
    { id = "posemod", v = "5" },
]
```

| Поле | Что означает |
| --- | --- |
| `id` | Уникальный ключ мода. Без пробелов и `;`. Регистр не важен. Совпадает с именем архива. |
| `name` | Отображаемое имя в каталоге. |
| `author` | Автор мода. |
| `type` | Раздел: `PM`, `Build`, `TR`, `ML`, `Mod`, `Plugin`, `Translate`. Одно значение. |
| `game_versions` | Совместимость с версией игры, см. ниже. Пусто — «неизвестно». |
| `mod_version` | Версия мода. Показывается и сравнивается именно она. |
| `tags` | До 5 тегов, латиница, нижний регистр, без пробелов. |
| `credits.*` | Ссылки автора: `boosty`, `discord`, `github`, `itchio`, `patreon`, `telegram`, `youtube`. |
| `description.en` | Английское описание. Обязательно. Показывается, если русского нет. |
| `description.ru` | Русское описание. Необязательно. |
| `description.videos` | Ссылки на YouTube. Каждая — отдельное превью с плеером. |
| `download.partN` | Тома архива: `url`, `size`, `sha256`. До 9 томов. |
| `files.config` | Путь к конфигу от корня сборки. Один файл. |
| `files.affected_files` | Файлы, которые мод заменяет. Для проверки конфликтов. |
| `files.installed` | Только для `Build`: моды, уже входящие в сборку. |
| `files.dependencies` | Зависимости: `id`, `v` (необязательно), `optional` (необязательно). |

Слэши в путях удваиваются (`\\`) или строка пишется в одинарных кавычках (`'BepInEx\config\BepInEx.cfg'`). Inline-таблица — одной строкой. `size` — числом, без кавычек. Пустая секция `[download]` = карточка «Скоро».

## Совместимость (`game_versions`)

| Значение | Смысл |
| --- | --- |
| `U20` | конкретная версия Unity |
| `U4-U6` | диапазон версий Unity |
| `>=U17`, `<=U20` | не старее / не новее указанной |
| `2021.02.01` | конкретная сборка |
| `2021.02.01-2021.10.01` | период |
| пусто `""` | неизвестно |

Один оператор и один диапазон на строку, без пробелов: `>=U17`, а не `>= U17`. `>=` и `<=` работают и с датами. Нераспознанное значение не скрывает мод: карточка показывает «совместимость неизвестна». Если версия игры не выбрана, проверка не выполняется и тег совместимости не показывается.

## Описание и видео

`description.en` обязателен, `description.ru` — по желанию. Если русского нет, английский показывается в обоих интерфейсах. Текст — обычная строка, без переносов, Markdown и HTML.

Ссылки на YouTube (`youtube.com/watch`, `youtu.be`, `shorts`) — только в `description.videos`, каждая с новой строки в массиве. Каждая даёт превью с встроенным плеером.

## Скриншоты и иконка

Изображения лежат в папке версии рядом с `info.toml`. Каталог читает их из репозитория, а не из архива.

- `1.webp` — обложка, `2.webp`, `3.webp` — остальные. Сортировка естественная: `2.webp` идёт раньше `10.webp`.
- `.gif` анимируется.
- `ico.webp` — квадратная иконка в углу обложки. Также понимаются `icon.webp` и `ico.png`.
- Если скриншотов нет, обложкой станет превью первого видео, затем иконка.
- PNG годится только для иконки. Скриншоты — webp или gif.

## README и CHANGELOG

`README.md` и `CHANGELOG.md` лежат в папке мода, рядом с папками версий. README показывается под описанием, changelog — в свёрнутом блоке «Изменения». Регистр имени не важен.
