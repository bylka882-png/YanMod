# YanMod

Моды, готовые сборки и переводы для Yandere Simulator. Архивы лежат в [Releases](https://github.com/bylka882-png/YanMod/releases), манифесты и изображения — в этом репозитории.

## Веб-каталог

`index.html` — один файл без зависимостей и сборки. Это та же страница, что открыта на GitHub Pages.

Что она делает:

- показывает все моды из репозитория;
- ищет по названию, автору и описанию;
- фильтрует по разделам `PM`, `Build`, `TR`, `ML`, `Mod`, `Plugin`, `Translate`;
- проверяет совместимость с выбранной версией игры (`U4`, `U5`, `U6`, `U17`, `U19`, `U20`) по полю `gameV`;
- в окне мода показывает версии, скриншоты и GIF, описание или исходный `info.yaml`, зависимости, `affected_files`, ссылки автора и видео YouTube;
- скачивает архив, включая многотомный: браузер получает все части.

Страница только скачивает файлы в папку загрузок. Она ничего не устанавливает и не распаковывает.

Открыть локально: сохранить `index.html` и дважды щёлкнуть. Нужен интернет — данные читаются из GitHub: список файлов через Tree API (при лимите запросов — через jsDelivr), манифесты с `raw.githubusercontent.com`. Кэш — 6 часов, кнопка «Обновить» загружает заново.

Без сети показывается последняя сохранённая копия, если она была. В приватном режиме браузер может запретить кэш. Для многотомного архива браузер может спросить разрешение на несколько загрузок.

Сама страница обновляется вместе с `index.html`: GitHub Pages отдаёт этот файл из репозитория.

## Скачать и установить

1. Открыть веб-каталог или [Releases](https://github.com/bylka882-png/YanMod/releases).
2. Выбрать мод и версию игры.
3. Скачать архив.
4. Установить через лаунчер YanLan или вручную: `Build` распаковать в отдельную папку, остальные моды — в корень сборки.
5. Многотомный архив: скачать все части и распаковать первую (`.001`).

## Структура

```
YanMod/
├─ build/       готовые сборки
├─ mod/         обычные моды
├─ PM/          Pose Mod
├─ TR/          текстуры
├─ ML/          загрузчики: BepInEx, PoseMod
├─ Plugins/     плагины BepInEx
├─ Translate/   переводы
├─ info.yaml    шаблон манифеста
├─ index.html   веб-каталог
└─ README.md
```

Один мод — одна папка: `info.yaml` и изображения рядом. Версии можно раскладывать по подпапкам:

```
ML/PoseMod/
├─ u19/info.yaml
├─ u20/info.yaml
└─ u5/2018.07.01/info.yaml
```

Манифесты с одинаковым `id` собираются в одну карточку, версии сортируются от новых к старым. Подпапки не обязательны — версию можно указать только в поле `v`.

## Манифест `info.yaml`

Шаблон — `info.yaml` в корне репозитория.

```yaml
id: "MyMod"
name: "Название мода"
by: "Автор"
credits: "https://t.me/author; https://discord.gg/invite"
v: "1.0"
gameV: ">=U17"
description: "Русское описание|English description"
DL_url: "https://github.com/bylka882-png/YanMod/releases/download/MyMod/MyMod.7z"
type: "Mod"
ioa: "PoseMod; 6"
cfg: "BepInEx/config/MyMod.cfg"
affected_files:
  - "BepInEx/plugins/MyMod.dll"
dependencies:
  - "PoseMod; 6"
```

| Поле | Что означает |
| --- | --- |
| `id` | Идентификатор мода. Одинаковый `id` у нескольких манифестов — версии одной карточки. Пусто — берётся из имени папки. |
| `name` | Название в каталоге. Пусто — `id`. |
| `by` | Автор. |
| `credits` | Ссылки автора: Discord, YouTube, GitHub и другие. Несколько — через `;`. Остальной текст игнорируется. |
| `v` | Версия мода. Пусто — имя папки, если оно похоже на версию (`5.4.21`). |
| `gameV` | Совместимость с версией игры, см. ниже. Пусто — «неизвестно». |
| `description` | Текст в формате `RU\|EN`. Если перевода нет, достаточно одной части. |
| `DL_url` | Прямая ссылка на архив. Пусто — карточка «Скоро». Несколько томов — через `;`. |
| `type` | Раздел: `Mod`, `PM`, `TR`, `ML`, `Build`, `Plugin`, `Translate`. Несколько — через `;`. Пусто — по верхней папке. |
| `ioa` | Только для `Build`: моды, которые уже входят в сборку (`"PoseMod; 5"`). Показываются в карточке. |
| `cfg` | Путь к конфигу от корня сборки. Нужен редактору конфигов. |
| `affected_files` | Список файлов, которые заменяет мод. Используется для проверки конфликтов. |
| `dependencies` | Список зависимостей в формате `"id; версия"`. Версию можно не указывать — подберётся совместимая. |

В `cfg` можно писать `BepInEx\config\Mod.cfg` или `BepInEx/config/Mod.cfg` — второй вариант проще, потому что не требует экранирования в YAML.

## Совместимость (`gameV`)

| Значение | Смысл |
| --- | --- |
| `U20` | конкретная версия Unity |
| `U19-U20` | диапазон версий Unity |
| `>=U17`, `<=U20` | не старее / не новее указанной |
| `2019.07.01` | конкретная дата сборки |
| `2017.10.04-2019.07.01` | период |
| `own` | своя версия, совместимость не проверяется |

Если версия игры не выбрана, проверка не выполняется и тег совместимости не показывается. Операторы `>=` и `<=` работают и с датами.

## Описание и видео

Формат — `RU|EN`. Если оставить только русский текст, он покажется и в английском интерфейсе.

Ссылки на YouTube (`youtube.com/watch`, `youtu.be`, `shorts`) вырезаются из текста и показываются отдельными превью со встроенным плеером. Каждую ссылку лучше ставить с новой строки.

## Скриншоты и иконка

Изображения лежат в папке мода рядом с `info.yaml`. Каталог читает их из репозитория, а не из архива.

- `1.webp` — обложка, `2.webp`, `3.webp` — остальные. Сортировка естественная: `2.webp` идёт раньше `10.webp`.
- `.gif` анимируется.
- `ico.webp` — квадратная иконка в углу обложки. Также понимаются `icon.webp` и `ico.png`.
- Если скриншотов нет, обложкой станет превью видео, затем иконка.
- PNG годится только для иконки. Скриншоты — webp или gif.

## Архивы и `DL_url`

Архивы в git не попадают — `.gitignore` исключает 7z, zip и rar. Они хранятся в Releases.

Прямая ссылка выглядит так:

```yaml
DL_url: "https://github.com/bylka882-png/YanMod/releases/download/MyMod/MyMod.7z"
```

Многотомный архив: первая часть — полный адрес, остальные — имена файлов в той же папке релиза.

```yaml
DL_url: "https://github.com/bylka882-png/YanMod/releases/download/ChristmasParty/ChristmasParty.7z.001; ChristmasParty.7z.002; ChristmasParty.7z.003"
```

Пустой `DL_url` — карточка «Скоро» без кнопки скачивания. Лаунчер понимает 7z, zip и rar; для многотомных архивов используйте 7z.

## Как добавить мод

1. Создать папку в нужном разделе: `mod/MyMod/`.
2. Скопировать `info.yaml` из корня и заполнить поля.
3. Положить `1.webp` и другие скриншоты, при желании `ico.webp`.
4. Упаковать мод в 7z, загрузить в Releases и скопировать прямую ссылку.
5. Вставить ссылку в `DL_url`.
6. Обновить каталог.

Отдельный индекс вести не нужно: каталог собирается из всех `info.yaml` в репозитории. В лаунчере и на странице кэш живёт 6 часов, кнопка «Обновить» сбрасывает его сразу.

## Права

Права на моды принадлежат их авторам. Репозиторий не связан с разработчиками Yandere Simulator. Если вы автор и хотите убрать мод из каталога — откройте issue.
