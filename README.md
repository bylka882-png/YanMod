# 🔪 YanMod

**Репозиторий модов и сборок для Yandere Simulator.** Все модификации упакованы в стандартизированный формат и доступны для скачивания в разделе [Releases](../../releases).

---

### 📦 Структура манифеста мода

Каждый мод в репозитории сопровождается `meta.yaml` файлом следующей структуры:

```yaml
id: "уникальный_айди"
name: "Название мода"
by: "Автор мода"
v: "Версия мода"
gameV: "Версия игры" # Если полноценный билд, указывается 'own'
description: "Описание мода"
DL_url: "Прямая ссылка на скачивание архива"
type: "Тип" # Допустимые значения: PM, build, TR, ML, mod
affected_files:
  - "Заменяемые файлы (для отслеживания конфликтов)"
dependencies:
  - "Зависимости, необходимые для работы"
```

---

### 🗂️ Допустимые типы модификаций (`type`)

- **`mod`** — обычный мод
- **`PM`** — мод для Pose Mod
- **`TR`** — замена текстур (Texture Replacement)
- **`ML`** — загрузчик модов (Mod Loader)
- **`build`** — полноценная готовая сборка игры

---

### 📥 Как скачать моды

1. Перейдите во вкладку **[Releases](../../releases)** этого репозитория.
2. Выберите нужный мод, ориентируясь на его версию и совместимость с вашей версией Yandere Simulator.
3. Скачайте архив по прямой ссылке или из вложений к релизу.
