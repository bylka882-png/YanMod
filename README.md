# 🔪 YanMod

**Централизованный репозиторий модов и сборок для Yandere Simulator.** Все модификации упакованы в формат `.7z`, содержат скриншоты `.webp` и доступны для скачивания в разделе [Releases](../../releases).

---

### 📦 Содержимое и формат мода

Каждый мод обязательно упаковывается в архив **`.7z`**. Внутри архива (или рядом с ним) поставляются:
1. **Изображения** — строго в формате **`.webp`** для демонстрации мода.
2. **Манифест** — файл `meta.yaml` со следующей структурой:

```yaml
id: "уникальный_айди"
name: "Название мода"
by: "Автор мода"
v: "Версия мода"
gameV: "Версия игры" # Если полноценный билд, указывается 'own'
description: "Описание мода"
DL_url: "Прямая ссылка на скачивание архива"
type: "Тип" # Допустимые значения: PM, build, TR, ML, mod
affected_files:
  - "Заменяемые файлы (для отслеживания конфликтов)"
dependencies:
  - "Зависимости, необходимые для работы"
```

---

### 🗂️ Допустимые типы модификаций (`type`)

- **`mod`** — обычный мод
- **`PM`** — мод для Pose Mod
- **`TR`** — замена текстур (Texture Replacement)
- **`ML`** — загрузчик модов (Mod Loader)
- **`build`** — полноценная готовая сборка игры

---

### 📥 Как скачать моды

1. Перейдите во вкладку **[Releases](../../releases)**.
2. Найдите нужный архив с расширением **`.7z`**.
3. Проверьте совместимость по описанию и манифесту, после чего скачайте файл.
