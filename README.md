# 🔪 YanMod

**Репозиторий модов для Yandere Simulator.** Все моды упакованы в формат `.7z`, содержат скриншоты `.webp` и доступны для скачивания в разделе [Releases](../../releases).

---

### 📦 Содержимое и формат

Каждый мод обязательно упаковывается в архив **`.7z`**. Внутри репозитория поставляются:
1. **Изображения** — строго в формате **`.webp`** для демонстрации мода.
2. **Манифест** — файл `info.yaml` со следующей структурой:

```yaml
id: "Уникальный_айди"
name: "Название мода"
by: "Автор мода"
credits: "Ссылка соцсети автора"
v: "Версия мода"
gameV: "Версия игры" # меньше или равно (<=); больше или равно (>=); 2017.10.04-2019.07.01 (период то есть сборки от 4 октября 2017 до 1 июля 2019); можно указать версию unity (U4/U5/U17/U19/U20/U6); own если сборка
description: "Описание мода"
DL_url: "Прямая ссылка на скачивание архива"
type: "Тип" # Допустимые значения: PM, Build, TR, ML, Mod, Plugin, Translate
affected_files:
  - "Заменяемые файлы (для отслеживания конфликтов)"
dependencies:
  - "Зависимости, необходимые для работы"
```

---

### 🗂️ Допустимые типы модификаций (`type`)

- **`Mod`** — обычный мод
- **`PM`** — мод для Pose Mod
- **`TR`** — замена текстур (Texture Replacement)
- **`ML`** — загрузчик модов (Mod Loader)
- **`Build`** — полноценная готовая сборка игры
- **`Plugin`** — плагин для BepInEx
- **`Translate`** — перевод для игры

---

### 📥 Как скачать моды

1. Перейдите во вкладку **[Releases](../../releases)**.
2. Найдите нужный архив с расширением **`.7z`**.
3. Проверьте совместимость по описанию и манифесту, после чего скачайте файл.
