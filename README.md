# 🔪 YanMod

**Репозиторий модов для Yandere Simulator.** Все модификации упакованы в `.7z`, снабжены скриншотами `.webp` и доступны в разделе [Releases](../../releases).

---

### 📦 Структура архива и манифест

Внутри каждого архива **`.7z`** находятся демонстрационные изображения **`.webp`** и файл манифеста `info.yaml`:

```yaml
id: "Уникальный_айди"
name: "Название мода"
by: "Автор мода"
credits: "Ссылка соцсети автора"
v: "Версия мода"
gameV: "Версия игры" # <=; >=; 2017.10.04-2019.07.01; U4/U5/U17/U19/U20/U6; own (для сборок)
description: "Описание мода"
DL_url: "Прямая ссылка на скачивание архива"
type: "Тип мода"
affected_files:
  - "Заменяемые файлы (для отслеживания конфликтов)"
dependencies:
  - "Зависимости"
```

---

### 🗂️ Допустимые типы модов (`type`)

* **`Mod`** — обычный мод.
* **`PM`** — мод для Pose Mod.
* **`TR`** — замена текстур.
* **`ML`** — загрузчик модов.
* **`Build`** — готовая сборка игры.
* **`Plugin`** — плагин для BepInEx.
* **`Translate`** — перевод игры.

---

### 📥 Как скачать

1. Перейдите в **[Releases](../../releases)**.
2. Выберите нужный **`.7z`** архив.
3. Проверьте совместимость по манифесту и скачайте файл.
