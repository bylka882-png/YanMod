# 🔪 YanMod

🌐 [English](README.md) | 🇷🇺 [Русский](README.RU.md)

**Репозиторий модов для Yandere Simulator.** Все модификации упакованы в `.7z`, снабжены скриншотами `.webp` и доступны в разделе [Releases](../../releases).

---

### 📦 Структура архива и манифест

В релизах находятся **`.7z`**, а в репозитории — демонстрационные изображения **`.webp`** и файл манифеста `info.yaml`:

```yaml
id: "Уникальный_айди"
name: "Название мода"
by: "Автор мода"
credits: "Ссылка на соцсети автора"
v: "Версия мода"
gameV: "Версия игры"
description: "Описание мода"
DL_url: "Прямая ссылка на скачивание архива"
type: "Тип мода"
affected_files:
  - "Заменяемые файлы (для отслеживания конфликтов)"
dependencies:
  - "Зависимости"
```

---

### 📉 Допустимые форматы версий игры (`gameV`)

* **`<=`** / **`>=`** — меньше/равно или больше/равно указанной версии.
* **`yyyy.mm.dd-yyyy.mm.dd`** — период сборки (от и до).
* **`U4`** / **`U5`** / **`U17`** / **`U19`** / **`U20`** / **`U6`** — конкретная версия движка Unity.
* **`own`** — для полноценных готовых сборок.

---

### 🗂️ Допустимые типы модов (`type`)

* **`Mod`** — обычный мод.
* **`PM`** — мод для Pose Mod.
* **`TR`** — замена текстур.
* **`ML`** — загрузчик модов.
* **`Build`** — готовая сборка игры.
* **`Plugin`** — плагин для BepInEx.
* **`Translate`** — перевод игры.

---

### 📥 Как скачать

1. Перейдите в **[Releases](../../releases)**.
2. Выберите нужный **`.7z`** архив.
3. Проверьте совместимость по манифесту и скачайте файл.
